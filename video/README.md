# JJ Furniture — pitch demo video (`video/`)

A 3:30, 1920×1080, 60 fps pitch video for the thesis/capstone defense. It is built with
[Remotion](https://www.remotion.dev) from **real screen captures of the app** (Demo Mode, the curated
5-order dataset). It is fully isolated from the Next.js app: its own `package.json`, excluded from the
app's `tsconfig.json` and ESLint, and it never touches app code, RLS or the database.

| Step | Command (run inside `video/`) | Output |
|---|---|---|
| 1. Start the app on a fresh demo | `cd .. && npm run build && PORT=3100 npm start` | in-memory demo, 5 curated orders |
| 2. Capture every scene from the real app | `npm run capture` | `public/clips/<scene>.mp4` + `<scene>.json` (cursor clicks, element boxes) |
| 3. Music bed + sound effects | `npm run audio` | `public/audio/*.wav` (original, synthesised: no licences needed) |
| 4. Narration | `npm run vo` | `public/vo/<line>.mp3` + `src/vo-manifest.json` |
| 5. Preview / edit | `npx remotion studio` | every scene is also its own composition |
| 6. Render | `npm run render` | `out/jj-furniture-pitch-demo.mp4` (H.264, AAC 48 kHz) |
| 7. 60-second ad | `npm run ad-music && npm run render:ad` | `out/jj-furniture-ad-60s.mp4` |

**60-second ad (`Ad60`).** A beat-synced highlight edit of the pitch timeline (`src/ad/AdVideo.tsx`: 17 cuts,
125 beats at 125 BPM = exactly 60 s), with its own narration (`src/ad/adScript.ts`, files `public/vo/ad-*.mp3`),
bold captions and an original energetic track (`scripts/make-ad-music.py`: drums, side-chained bass, chord stabs,
arpeggio, riser + drop, ending hit). If Remotion cannot download its browser, set `REMOTION_BROWSER` to a local
headless Chromium.

**Narration.** The script lives in `src/script.ts` (the same text is used for captions). The voice is
ElevenLabs "Clementine 2.0 – Upbeat, Engaging, Clear" (English, female). `npm run vo` reads
`ELEVENLABS_API_KEY` from the environment or `video/.env.local` (git-ignored) and never prints it. Without a
key, missing lines render silently with on-time captions.

**Licences.** The music and effects are generated by `scripts/make-audio.py`. The narration was made on an
ElevenLabs free plan, whose terms allow non-commercial use with attribution ("Voice: ElevenLabs"). Use a paid
plan before any commercial use. Remotion is free for individuals and teams of up to 3.

**Honest footage.** Everything on screen is the real app. The caramel cursor ring, click ripples, captions,
role chips, the 30% gate meter and the 7-stage tracker sweep are motion-graphic overlays added in Remotion.
Button labels are the app's real ones (e.g. "Release to workshop", not "Authorize for Production").
